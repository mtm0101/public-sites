# Generic Test Simulator

The Test Simulator is exam-neutral infrastructure. TOEIC grammar is the first bank; later AWS, IELTS, certification, or other test families use the same manifest, pack, definition, attempt, and review model.

## Runtime routes

- `#/tests`: catalog and resume card
- `#/tests/{testId}`: fixed-test detail and question list
- `#/tests/create`: filtered/adaptive generator
- `#/test-attempt/{attemptId}`: one-question testing UI
- `#/test-review/{attemptId}/{all|wrong|correct}/{questionId?}`: result and detailed review
- `#/tests/history`, `/wrong`, `/bookmarks`, `/categories`, `/bank`: user and source reporting

## Published JSON

Root: `data/chatgpt/tests/`.

- `manifest.json` discovers immutable packs and fixed definitions.
- `taxonomy.json` owns stable category IDs.
- `question-bank/{family}/{domain}/pack-NNNN.json` owns questions.
- `definitions/*.json` owns fixed tests as ordered `questionIds`.
- `bank-stats.json` is generated, not hand-edited.

Published question IDs and versions are immutable. Correct mistakes by publishing a new question version/ID and a new test-definition version; never reuse an ID for different content. Attempts store the exact ordered IDs plus pack versions so later additions do not alter history.

## Question contract

Every question has one exact `primaryCategoryId`, optional secondary categories, CEFR, difficulty 1–5, target score range, English and Vietnamese prompt/options, exactly four options, one correct answer, detailed bilingual explanation for every option, a rule summary, stable version, and content fingerprint. IPA stays runtime-generated by the app's shared US/UK IPA service.

## Modes

- Training (default): first choice is locked, answer and every option explanation appear immediately, score updates live.
- Real test: choices remain editable and feedback/score stay hidden until submission.
- Switching is always allowed. Entering training reveals and locks existing answers. Any attempt that exposes feedback is marked `assisted` so it is not confused with an unassisted exam result.

## Persistence and sync

Attempts are individual IndexedDB `meta` records named `testAttempt:{attemptId}`. Autosave occurs after answer, navigation, mode switch, and finish. The S3 activity export includes only those test-attempt meta records plus sessions. Fixed source JSON is never mutated by user activity.

## Content generation

Read `prompts/chatgpt/test-question-bank.md`, use `data/templates/test-template.json`, add a new pack instead of modifying a published pack, then run:

```powershell
python scripts/validate_test_bank.py
```

The initial TOEIC bank contains 200 original Part 5-style grammar questions: 20 categories × 10 questions, B2/C1, difficulty 3–5, aimed at advanced study around TOEIC 700–990. Scores in the app are raw percentages, not official TOEIC scaled scores.
